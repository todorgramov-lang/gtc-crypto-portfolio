# Крипто портфолио — GTC

Уеб приложение за проследяване на крипто портфолио: **BTC, ETH, SOL, HYPE**.
Слага се на началния екран на iPhone-а като Корфу и Страсбург — без Mac, без
Apple ID, без изтичане.

Данните остават на устройството. Няма акаунт, няма сървър, няма реклами.

---

## Пускане

```bash
cd crypto-portfolio && npm install && npm run dev
```

Отваря се на `http://localhost:5185`.

| команда | какво прави |
|---|---|
| `npm run dev` | локален сървър за разработка |
| `npm run build` | прави `dist/` за качване |
| `npm run preview` | преглед на готовия билд |
| `npm test` | тестовете върху изчисленията |
| `npm run icons` | пре-генерира иконките от `scripts/build-icons.mjs` |

---

## Как се слага на телефона

1. Качи съдържанието на `dist/` където хостваш Корфу и Страсбург.
2. Отвори адреса **в Safari** на iPhone-а (не в Chrome — само Safari може да
   инсталира на началния екран в iOS).
3. Бутонът за споделяне → **Add to Home Screen**.
4. Готово. Отваря се на цял екран, със собствена иконка, и работи офлайн.

Нова версия: качваш новия `dist/` и приложението само се обновява при следващото
отваряне (`registerType: 'autoUpdate'`). Версията се вижда в Настройки → Информация.

## Откъде идват цените

| приоритет | източник | кога |
|---|---|---|
| 1 | Binance WebSocket `@ticker` | винаги, докато връзката е жива |
| 2 | Hyperliquid WebSocket `allMids` | автоматично, ако Binance не достави тик за даден актив в първите 12 секунди |
| 3 | CoinGecko REST, на 30 сек | когато няма живи потоци; на 10 мин за курса EUR/USD |
| 4 | Локален кеш | при офлайн старт — с етикет „офлайн“ |

Reconnect с exponential backoff 1s → 30s. При 429 се изчаква според `Retry-After`.
Когато приложението е скрито, потоците се затварят, за да не се топи батерията.

Графиките идват от Binance `/api/v3/klines`, с автоматично превключване към
CoinGecko `market_chart` за символи, които Binance не поддържа.

## Изчисления

Всяка сметка минава през `decimal.js`. Никъде няма плаващи числа за пари —
`0.1 + 0.2` дава точно `0.3`, което има отделен тест.

```
Наличност           = Σ(buy + transferIn) − Σ(sell + transferOut)
Средна цена         = Σ(qty_buy × price_buy + fee_buy) / Σ qty_buy
Инвестирана сума    = Наличност × Средна цена
Текуща стойност     = Наличност × Текуща цена
Нереализирана П/З   = Текуща стойност − Инвестирана сума
Нереализирана П/З % = (Нереализирана П/З / Инвестирана сума) × 100
Реализирана П/З     = Σ [ qty_sell × (price_sell − себестойност) − fee ]
```

Себестойността при продажба зависи от метода в Настройки:

- **Средно претеглена (по подразбиране)** — движеща се средна към момента на
  продажбата. Продажбите не местят средната цена, затова тя е стабилна и след
  частична продажба. `transferIn` увеличава наличността без себестойност —
  въведи покупка, ако искаш активът да влезе в средната цена.
- **FIFO** — първите придобити партиди се продават първи.

Базовата валута е USD. EUR е само слой при показване, по курс от CoinGecko.

## CSV

```csv
date,asset,type,quantity,price,fee,exchange,note
2025-01-15T10:30:00Z,BTC,buy,0.05,42000.25,3.5,Binance,DCA
2025-02-02T08:00:00Z,HYPE,buy,120,18.4,0,Hyperliquid,
```

`type`: `buy`, `sell`, `transferIn`, `transferOut`. Цената и таксата са в USD.
При импорт се приемат и `yyyy-MM-dd` и `dd.MM.yyyy`. Повторен импорт на същия
файл не създава дубликати.

## Какво съзнателно го няма

- **Widget на началния екран** — iOS не дава widget-и на уеб приложения.
- **Заключване с Face ID** — също не е достъпно за уеб.
- **Ценови аларми във фонов режим** — без сървър няма как да се задействат,
  докато приложението е затворено.

Първите две изискват native приложение и Mac. Кодът за такова стои в
`../GTC-Crypto/`, ако някога се стигне дотам.

## Ограничения по замисъл

Приложението не дава инвестиционни съвети, прогнози или сигнали, не се свързва
с борсови акаунти, не иска API ключове и не изпраща никакви данни навън —
единствените изходящи заявки са към публичните ценови endpoint-и на Binance,
Hyperliquid и CoinGecko.
